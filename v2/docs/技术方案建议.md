# LiteERP Web 版 — 技术方案建议（v2，按 APB 接入方案修订）

> 上一版建议见 `archive/v1-ribbon-20261019/docs/技术方案建议.md`。本版根据 `design_handoff_apb_liteerp/`（APB 样式交付包 v1.0，2026-10-20）修订：LiteERP 作为 **APB 中控里的独立 ERP 模块**，APB 提供外壳，ERP 只绘制内容区。

## 1. 结论

| 层 | 建议 | 变化与理由 |
|---|---|---|
| 后端 | **Python 3.12 + FastAPI + SQLAlchemy 2 + Alembic** | 不变。APB 中控本身就是 FastAPI + Jinja2，同技术栈便于接入、鉴权、部署与运维协作 |
| 数据库 | **PostgreSQL 16** | 不变。金额用 `NUMERIC(14,2)`（或最小货币单位整数），不用浮点 |
| 前端 | **Vue 3 + TypeScript + Vite，组件自建（基于交付包的 `apb-erp-*` 类与 token）** | **改变**：交付包要求不得引入会影响宿主的全局 reset / 主题覆盖（Tailwind preflight、Element/Ant 全局样式等）。TDesign 等组件库的全局样式与此冲突，因此不再推荐整套组件库；表格、表单、对话框按本原型的组件封装成 Vue 组件即可（原型已验证 DOM 结构与交互） |
| 接入方式 | 首选：APB 同文档内容模块（`/admin/liteerp/`，静态资源 `/static/liteerp/`）；备选：iframe；盒端单独适配 | 见交付包 INTEGRATION.md。路径为建议，需与 APB 组确认后注册 |
| 部署 | Ubuntu 24.04 + Nginx + Gunicorn/Uvicorn（systemd）或 Docker Compose | 不变；ERP 资源独立版本，故障时撤掉 ERP 入口不影响 APB |

## 2. 本次交付（`v2/`）

- 纯静态原型，样式直接使用交付包 `assets/tokens.css` + `assets/apb-erp.css`（原样），扩展组件在 `assets/liteerp.css`（全部限定在 `[data-apb-erp]`，只用 token）。
- `index.html` 带一个模拟 APB 外壳便于预览；`index.html?mode=embedded` 只显示 ERP 内容区（即接入后的样子）。
- 页面形态按交付包规范重做：工具栏筛选 + 语义表格 + 分页；详情/新建/编辑为独立路由页面；对话框仅用于短操作；所有状态有文字；首次为空 / 无匹配 / 读取中 / 读取失败（`?demo=fail`）分别呈现；表单校验、首错聚焦、忙碌防重、离开保护。
- 用途：需求确认 + 界面评审 + 正式开发的组件与字段参考。`data.js` 与各页面的数据结构是数据库设计初稿。

## 3. 正式开发要点（来自交付包，需在后端落实）

| 项 | 要求 |
|---|---|
| 鉴权 | 以服务端校验为准；401 走宿主重新认证，403 停止操作并刷新能力；不靠隐藏按钮鉴权 |
| 列表 | 后端分页（默认 20，可选 20/50/100）或 cursor；关键词、筛选、排序、页码写 URL；请求用 AbortController + 序号防旧结果覆盖 |
| 写入 | 幂等键、乐观版本（409 冲突保留输入并允许重读对比）；超时“结果未知”先查回执，不盲目重试（尤其收款、打印） |
| 金额 | decimal 或最小货币单位；显示千分位两位小数，表头写“元” |
| 时间 | 日期 `YYYY-MM-DD` 不转时区；事件时刻后端带时区返回，显示 Asia/Shanghai |
| 状态 | ERP 订单状态与 APB 生产状态分列；无记录显示“未知”，不渲染成成功 |
| 财务 | 不替代 APB 现有账本或伪造入账；与 APB 财务的接点需双方确认 |

## 4. 接线前需要双方确认（交付包 INTEGRATION.md 第 5 节）

1. 实际入口：中控同文档 / iframe / 盒端；静态路径、路由与刷新深链。
2. 登录与权限：租户/代理商范围、只读状态、能力字段、CSRF、会话过期。
3. 数据合同：ERP 订单 ID 与 APB job/part/execution ID 的关联、状态字典、分页方式。
4. 写入合同：打印、库存、财务的动作、幂等、回执查询。
5. 文件：客户文件的预览/下载授权（替代旧版“本机文件夹”）。
6. 发布与回退：独立资源版本，撤掉 ERP 入口不影响 APB。

## 5. 数据迁移与开发顺序

不变（见 v1 文档）：请提供旧系统数据库备份；先做系统基础资料 → 客户/工单/收款闭环 → 预存与财务 → 报表 → 迁移与并行试运行。
