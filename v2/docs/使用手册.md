# LiteERP v2 使用手册

适用版本：LiteERP v2 静态原型（2026-10-19 版）。本手册说明怎样打开系统、通用操作和各模块的日常用法。

> 原型说明：现在的数据是内存中的演示数据，**刷新页面就会还原**。打印、扫码付款、推送收银台只做演示，不会真的打印或收钱。

---

## 1. 打开系统

| 方式 | 地址 | 说明 |
|---|---|---|
| 预览 | `index.html` | 带模拟的 APB 顶栏和左侧导航 |
| 接入效果 | `index.html?mode=embedded` | 只显示 ERP 内容区，即接入 APB 后的样子 |
| 直接打开某页 | `index.html#/页面编号` | 例如 `#/custManage`、`#/orderDetail?no=GD26082210047` |

本地使用时，直接双击 `index.html` 即可，推荐 Chrome 或 Edge 浏览器。服务器部署见 `README.md`。

左侧导航分六个模块，每个模块有一个“业务中心”首页：

| 模块 | 首页 | 主要内容 |
|---|---|---|
| 前台 | 前台业务中心 `#/frontdesk` | 开单、工单、云端订单、结算记录、预存、会员卡、零收、营业日报 |
| 生产 | 生产业务中心 `#/prodCenter` | 在制工单、流程转单、制作明细 |
| 财务 | 财务业务中心 `#/finCenter` | 收款结算、转账、收支、应收、销账、对账、期末结账 |
| 客户 | 客户资料 `#/custManage` | 客户档案、联络人员、分组价格、协议价格、合并、价格复制 |
| 报表 | 报表中心 `#/reportCenter` | 9 张统计报表、业务提醒 |
| 系统 | 员工资料 `#/employees` | 员工、角色、经营项目、客户分组、生产流程、科目、参数、打印样式、导入 |

## 2. 通用操作

### 2.1 列表（台账）

- **搜索**：在搜索框输入，停顿约 0.3 秒自动筛选；中文输入法打完字再筛选。
- **筛选**：下拉框、日期范围（可选今天、昨天、本月、上月、近 30 天、今年、全部，或自定义）。
- **分页**：每页 20 / 50 / 100 条，底部翻页。
- **勾选**：表头复选框只勾选**当前页**。勾选后上方出现批量按钮（如“导出所选”“我来处理”“批量收款”“审核所选”）。
- **合计**：金额列在表格底部显示合计。
- **导出**：“导出所选”或报表的“导出”生成 CSV 文件，可直接用 Excel 打开。
- **记住条件**：筛选、页码会写进地址栏。刷新、返回或把链接发给同事，都能看到同样的结果。
- 列表为空时会说明原因：“还没有数据”和“没有符合条件的数据”是两种提示；读取失败时会提示，可重新读取。

### 2.2 表单

- 带 `*` 的是必填项。点“保存”时如有错误，表单顶部列出全部问题，并自动定位到第一个出错的字段。
- 保存过程中按钮显示加载状态，不能重复点击。
- **未保存提醒**：表单改过但没保存，离开页面（点导航、返回、关闭标签页）会弹窗确认“放弃修改”。

### 2.3 删除和不可撤销的操作

删除、反审核、客户合并、期末结账等操作都会先弹出确认框，写明后果。客户合并和期末结账**不能撤销**。

## 3. 前台

### 3.1 新建工单 `#/newOrder`

1. **选择客户**，有三种：
   - 散户：编号 000000，适合临时客户；
   - 选老客户：可输入名称首字快速定位；
   - 建新客户：填名称、手机、分组，保存工单时同时建档。
2. 填写联系人、电话、交付日期、制作任务、取送要求、工单类型和制作要求（最多 500 字）。
3. 点 **“添加经营项目”**，先选经营主项再搜索子项。可以连续添加多项。
4. 在明细表里修改份数、每份数量、实价，金额自动计算。份数填 0 的行不计费。
5. 保存。工单号自动生成（GD + 日期 + 序号）。没有明细也能保存，即“0 元空单”。

**取价顺序**：客户协议价格 → 客户分组价格 → 标准单价 × 分组折扣。

### 3.2 前台业务中心 `#/frontdesk`

列出接待中的工单，可按结算状态、生产流程、委托日期筛选。

- 结算状态：0 元空单 / 尚未结算 / 部分结算 / 完成结算。
- 生产流程按“生产流程”设置的顺序显示，最后一个流程表示完工。
- 结算状态与生产流程**分开记录**，互不影响。
- 批量操作：导出所选、我来处理（把工单的“当前处理人”设为自己）。

### 3.3 工单详情 `#/orderDetail?no=工单号`

点工单号进入。顶部按钮：

| 按钮 | 作用 |
|---|---|
| 收款结算 | 收款，可部分收款。见下表 |
| 收款码 | 生成付款码、复制付款链接、推送收银台（演示） |
| 流程转单 | 推进到下一个生产流程，可填转单说明 |
| 编辑 | 修改工单资料和明细。已审核的工单要先反审核；修改后的金额不能低于已收金额 |
| 审核 / 反审核 | 审核后资料只读 |
| 打印 | 按“打印样式”中的默认样式打印（演示） |

**收款时的支付方式**：

| 支付方式 | 结果 |
|---|---|
| 现钞、微信、支付宝、刷卡、转账 | 实收入账，需选择入账科目（现金或银行账户） |
| 记账 | 不收钱，生成记账单计入客户欠款，以后在“销账”中收回 |
| 预存扣款 | 从客户的会员卡余额扣款；客户没有会员卡或余额不足时不能使用 |

### 3.4 其他前台页面

| 页面 | 地址 | 说明 |
|---|---|---|
| 工单记录 | `#/orderRecords` | 全部工单的查询台账；可切换全面列 / 基础列 |
| 云端业务中心 | `#/cloudCenter` | 微信小程序、公众号、网页商城的订单；受理后自动生成工单 |
| 结算记录 | `#/settleRecords` | 实际到账的收款单；“基础”视图含记账、预存扣款、优惠等全部方式 |
| 预存储值 / 预存退款 | 预存记录页、会员卡详情页按钮 | 给会员卡充值或退款；充值可同时赠送金额（示例规则：满 1000 送 20%，满 5000 送 10%）并调整客户分组，赠送部分单独记账 |
| 预存记录 | `#/prestoreRecords` | 储值与退款单据，退款为负数 |
| 会员卡资料 | `#/cardInfo` | 卡片发行、锁定、挂失、注销；新卡余额为 0 |
| 卡片发行 | `#/cardIssue` | 绑定已有客户，或同时新建机构 / 个人客户 |
| 零收 | `#/miscIncome` | 不开工单的零散收入（复印、打印、扫描），直接收款 |
| 零收记录 | `#/miscIncomeRecords` | 含手动登记和云端交易自动生成的零收 |
| 营业日报表 | `#/dailyReport` | 汇总指定时间内的结算、预存、零收、一般收支 |

## 4. 生产

- **生产业务中心** `#/prodCenter`：在制工单，可按生产特征（我处理的 / 无人处理 / 未完工）、生产流程、交付预警筛选。点行内“流程转单”推进到下一流程；勾选后可批量“我来处理”“导出所选”。
- **制作明细记录** `#/prodDetail`：把工单展开到每一行明细，按经营项目核对数量和金额。

## 5. 财务

### 5.1 财务业务中心 `#/finCenter`

按“支付方式、现金、应收、预存”四栏汇总财务单据的增减。点任一汇总数字，下方只显示对应的明细。顶部可进入新建转账、一般收入、一般支出、新建销账。

### 5.2 收款

- **智多结算中心** `#/smartSettle`：列出未结清的工单。
  - 单张收款：点行内“收款”；
  - 批量：勾选当前页工单后，点“批量收款”或“转记账”。

### 5.3 资金

| 页面 | 说明 |
|---|---|
| 现金余额 / 银行余额 | 各资金科目的当前余额和流水 |
| 新建转账 `#/transfer` | 现金与银行之间划转（存现、取现、平台提现）。未审核的转账可删除，删除时冲回两边余额 |
| 一般收入 / 一般支出 | 工单以外的收支，如房租、水电。未审核的可删除 |
| 收支记录 `#/generalRecords` | 一般收入、支出单据台账 |

### 5.4 应收与销账（记账客户的完整流程）

1. 开单后，收款时选“记账”，形成客户欠款；
2. 在 **客户对账** `#/custStatement` 查看客户的结算单据和工单，可打印对账单；
3. 客户付款后，在 **新建销账** `#/writeOff` 选择要冲销的记账单，登记收款；
4. 在 **销账记录** `#/writeOffRecords` 审核。审核前，这笔钱计入客户的“销账未审”；
5. 用 **客户结余** `#/custBalance` 和 **应收汇总** `#/arSummary` 核对每个客户的欠款和预存。

> 删除结算单时，系统会冲回对应的资金、欠款或会员卡余额。如果这笔记账已经部分销账，系统不允许删除，需先删除销账单。

### 5.5 期末结账

1. 在 **会计日历** `#/accountCalendar` 设好会计年度各期间的起止日期（自然月或固定结账日）；
2. 审核本期全部财务单据（各记录页可“审核所选”）；
3. 在 **期末结账** `#/periodClose` 执行结账，存档本期数据并开始新期间。结账不能撤销。

## 6. 客户

| 页面 | 地址 | 说明 |
|---|---|---|
| 客户资料 | `#/custManage` | 客户台账；“全面”视图显示账务、开票等全部列 |
| 客户详情 | 点客户编号 | 基本资料、联系人、工单、结算、会员卡、协议价格等综合信息 |
| 新建机构 / 个人客户 | 客户资料页按钮 | 机构客户可登记多位联络人员 |
| 联络人员 | `#/contacts` | 机构客户的经办人、财务、设计师等 |
| 分组价格 | `#/groupPrice` | 给某个客户分组设定统一单价 |
| 协议价格 | `#/agreementPrice` | 单个客户的专属单价，开单时最优先 |
| 客户合并 | `#/custMerge` | 把重复的来源客户并入目标客户；工单、结算、会员卡、欠款等一并转移，来源客户删除。**不能撤销** |
| 价格复制 | `#/priceCopy` | 把一个客户的协议价格复制给另一个客户，可按项目或按主项整批复制 |

客户编号自动生成，不会重复。已有工单、结算、预存、欠款等记录的客户不能删除，重复建档的请用“客户合并”。散户 000000 是系统默认客户，不能删除。

## 7. 报表

**报表中心** `#/reportCenter` 共 9 张报表：

- 营业收支汇总表、工单结算汇总表、经营项目汇总表；
- 客户价值分析表、客户新增汇总表、会员办卡汇总表；
- 客户工单实收排行表、客户工单均价排行表、客户工单数量排行表。

使用方法：设置时间范围和汇总依据 → 点“统计” → 在“数据表格”和“数据图表”之间切换 → 需要时点“导出”。查询条件保存在地址中。

**业务提醒** `#/bizAlert`：交付超期、未结算、欠款超限、预存余额不足、未审核单据。提醒阈值可以调整。

> 原型中“审核时间”暂以工单登记时间代替。

## 8. 系统设置

建议新门店按下面的顺序设置：

1. **会计科目** `#/chartOfAccounts`：“银行存款”下的科目就是收款时可选的资金账户。
2. **生产流程** `#/prodFlow`：编号最小的是新单默认流程，编号最大的视为“完工”。
3. **经营项目** `#/bizItems`：先建经营主项，再建子项（名称、单位、单价）和规格。
4. **客户分组** `#/custGroups`：设定默认折扣和预存规则。修改分组编号时，分组价格和相关工单、会员卡会同步更新。
5. **基础数据** `#/baseData`：制作任务、结算方式、部门岗位等下拉选项。
6. **角色配置** `#/roles` 和 **员工资料** `#/employees`：员工编号就是登录账号；停用的角色不能登录；有业务单据的员工不能删除，请改为“离职”。
7. **运行参数** `#/runParams`、**打印样式** `#/printStyles`：每种单据可有多个打印样式，打印时用“默认”样式。
8. **数据导入** `#/dataImport`：从 CSV 批量导入客户、经营项目、员工。按编号判断记录是否已存在：新编号新增；已存在的默认跳过，选择“覆盖更新”才会更新。

## 9. 常见问题

**刷新后我录入的数据没了？**
这是原型，数据只在内存里。正式版会接数据库（建议 PostgreSQL，见 `docs/技术方案建议.md`）。

**为什么不能删除某个客户 / 员工 / 角色？**
已经有业务单据的记录不能删除，以免账目对不上。重复的客户用“客户合并”，员工改为“离职”，角色先把员工改到别的角色。

**工单改不了金额？**
已审核的工单先“反审核”。另外，修改后的金额不能低于已经收到的金额，如需退款请先删除对应的结算单。

**结算单删不掉？**
已审核的单据要先反审核；记账单如果已经部分销账，要先删除对应的销账单。

**页面显示“读取失败”？**
刷新页面重试。正式版中通常是网络或服务器问题，请联系管理员。
